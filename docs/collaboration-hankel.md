# 与汉高战略部实习生的协作

> 本项目的目标用户场景需要通过访谈校准。本文件汇总：访谈题目、需要他提供的材料、访谈节奏。
> 完整原文见 [PRD.md §14](PRD.md#十四待办与未决问题)。

## 访谈节奏

| 时间点 | 目的 | 问题组 |
|---|---|---|
| **Week 0 / 启动前** | 校准 Schema 与价值主张 | A + B + E + F |
| **Week 0.5 内** | 收材料 | （见下方材料清单） |
| **Week 2 联调期** | 拿初版 demo 试用 → 收反馈 | D + 信任度 |

---

## 访谈题目

详见 [PRD.md §14.1](PRD.md#141-需要与汉高战略部实习生访谈业务侧他能回答)，共 6 组：

- **A. 工作流与场景**（必问）
- **B. 字段与维度**（验证 Schema 设计，必问）
- **C. 信息源**（决定采集 Agent 的价值边界，必问）
- **D. 报告交付物**（决定导出功能优先级，必问）
- **E. 痛点与期望**（验证价值主张，必问）
- **F. 问卷调研与用户访谈**（决定 `generate_survey` 是 P0 还是降级，必问）

---

## 需要他提供的材料

- [ ] **脱敏的真实竞品分析报告**（PPT 或 Word）—— 用作 Schema 和报告排版的参照基准
- [ ] **汉高内部竞品分析框架/模板**（如有）—— 行业 know-how
- [ ] **常用付费数据库/工具清单**（尼尔森、欧睿、Mintel 等）—— 判断 P2 是否要支持外部数据导入
- [ ] **1-2 个具体竞品分析案例**（产品 + 竞品列表）—— 作为演示备选案例

---

## 重要：在拿到反馈前的默认决策

- CollectorAgent 的 `generate_survey` 工具按 **"流程模拟"** 实现（LLM 生成方案 + 模拟数据），**不要过度设计**
- 用户画像字段先按通用结构化方案（年龄段 / 地域 / 职业 / 需求 / 痛点）实现，等访谈后调整颗粒度
- 演示行业先用 SaaS / 通用消费品类（材料相对公开），最终演示行业等访谈拿到案例后再定
