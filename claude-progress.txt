## 📊 关键指标（业务闭环量化，claim 级 / 定义见 PRD §十三）

> claim = 报告中带 source_ids 的节点（PRD §7.9）；T = claim 总数。一律 claim/字段级，不用字数。
> 「当前」列在 S4 真跑 3 竞品时采集真实值；现阶段为占位。

| 指标 | 公式 | 目标 | 当前 | 优先级 |
|------|------|------|------|--------|
| 分析耗时 | completed_at − started_at | <10 min | - | P0 |
| 字段覆盖率 | 已填核心必填字段 / 应填核心字段 | ≥95% | - | P0 |
| 引用覆盖率 | 有 source 的 claim / T | ≥90% | - | P0 |
| 人工修正率 | 被改 claim / T（按 correction_type 拆 5 类） | 越低越好 | - | P0 |
| 人工确认准确率 | (正确 + 0.5×部分) / 抽检数 | >85% | - | P0 |
| 需求覆盖率 | 已完成维度 / 要求维度 | 100% | - | P1 |
| 来源支撑率 | QA 判源支撑的 claim / T | >80% | - | P1 |
| 信息源类型覆盖率 | 命中 category 数 / 5 | ≥4/5 | - | P1 |
| 无效来源率 | valid=false / source 总数 | 越低越好 | - | P1 |
| 重跑率 | 重生成模块 / 总模块 | 越低越好 | - | P1 |
